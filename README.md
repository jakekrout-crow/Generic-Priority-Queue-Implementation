# <Generic-Priority-Queue-Implementation>

# Description

This project was made as part of an assignment for a CS2000 class
this project was made with the goal of gaining a better understanding of how to implement a priority queue with a wide variety of data types

# Usage

to test this code's ability to organize a queue it can be run with the built in test cases, or you can go into the code blocks and change them. in order to not break the program, strings should only be replace with strings, and numbers should only be replaced with numbers. 

if you would like to alter the test data, you will find it under the following functions: 

_test_task_data_type()

_test_patient_data_type()

_test_single_item()

_test_same_priority_items()
